# better-agents

Records of experiments on how coding agents behave in this repository and what
changes their behavior. Each session gets one log plus the primary material it
rests on, so that a later analysis can re-check the claims rather than trust the
summary.

| Date | Log | Question | Result |
|---|---|---|---|
| 2026-10-10 | [session-2026-10-10_test_instructions.md](session-2026-10-10_test_instructions.md) | Where does an agent put a new test, and does a root instruction file that points to `docs/testing/testing-strategy.md` change that? | 0 of 11 correct placements without the file, 10 of 10 with it. |

Supporting material for 2026-10-10: `prompts.md`, `runs.csv`, `audits/`, `patches/`.
